# CLAUDE.md

**Read [`AGENTS.md`](AGENTS.md). That is the manual.** All the rules are there — how to talk to me, what doesn't go into the brain, when to ask and when to just do it.

This file has no rule that isn't already in `AGENTS.md`. That is on purpose: the same thing in two files drifts apart sooner or later.

---

**Why this file exists at all:** Claude Code reads `CLAUDE.md` automatically, every time you open a chat. Other tools don't — they look for `AGENTS.md`. This file is just a signpost so both end up in the same place.

If you open your brain with another AI and it doesn't know what to do, tell it: **"read AGENTS.md"**.
