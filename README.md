# My business brain

> Your brain is a folder of plain text files that your AI can read and write. Nothing more. All the magic is that it's in one place and always with you.

This folder is almost empty right now. **That's how it should be** — it fills up as you do your real work here.

---

## Start here

1. **Tell your AI:** *"Read through my brain and tell me what's here and what is still empty."*
2. **Open [`TOPICS.md`](TOPICS.md)** — nine topics your brain wants to know about you. Start with the first two.
3. **Open [`HOW-TO-USE.md`](HOW-TO-USE.md)** — ready-made sentences you can copy straight in. Including questions you ask your brain yourself, once something has built up in it.

**One habit that holds it all together:**

> **Finish by saving.**
> When you're done: *"save all changes to the main version on GitHub."*

In the browser, every new chat starts from the latest version on GitHub — there's nothing to download. But the AI makes its changes in its own copy and then waits. If you don't say "save", they stay on a side branch. The next chat often finds them and asks, but not always. Only the main version is certain.

## Two questions before every file

1. **Can this file stay in GitHub's history?**
2. **Can the AI service provider process its contents?**

| Material | In GitHub's history? | Can the AI process it? | Where |
|---|---|---|---|
| Distilled business knowledge and procedures | Yes | Yes | Brain folders |
| Raw material, working documents, client files | No | Yes, if the tool is allowed for it (see risk assessment) | Agent account Drive |
| Material the AI must not process | No | No | Stays where it is; doesn't go to the agent account |
| Passwords, API keys, logins | No | No | Password manager or a secure setting |

Opening a Drive file in the AI means the AI provider processes its contents — even if the file never goes to GitHub.

**Distil, don't dump.** The brain is not a rubbish bin. Raw chat logs don't go here — what goes here is what the AI took out of them.
